# Retomar Vilazuni

Consultar primeiro [STATUS_DO_PROJETO](STATUS_DO_PROJETO.md) e os critérios atuais das [etapas 6](fundacao/ETAPA_6_FONTES_E_GOVERNANCA.md) e [7–8](fundacao/ETAPAS_7_8_DISTRIBUICAO.md).

Usuário pediu concluir as etapas de desenvolvimento e avançou para a implantação: VPS Hostinger com Easypanel em Campinas/SP e domínio próprio adquiridos. O usuário iniciou modificações pontuais: personagens/fichas de síndico e zelador, mural com leitura individual e modernização da navegação. Município do condomínio confirmado: Arraial do Cabo/RJ. A implementação financeira permanece **manual**. O usuário confirmou interesse em **Asaas** e **WhatsApp** no próximo ciclo e pediu comparação com Mercado Pago; não ativar cobrança ou mensagens reais com base apenas na pesquisa.

Usar o checkout existente. Instalar pelo lockfile com `npm ci --prefix app --ignore-scripts`; validar `npm test --prefix app` e, para interface, `npm run test:browser --prefix app`. Testes PostgreSQL exigem configuração descartável local; nunca apontar testes ou restauração a produção.

Servidor local: `npm start --prefix app`, loopback padrão 4173. Não criar conta/senha do usuário. Não iniciar dois processos sobre a mesma base JSON. Bases e chaves estão fora do Git. O usuário realizou a implantação web inicial; em 21/10/2026 foram conferidos HTTPS, `/healthz` e `/readyz` com 200 e `/api/state` com 401 sem login. O usuário criou a conta de gestão e a captura confirmou MFA ativo. Próxima tarefa operacional: conferir volume/backup e recuperação, homologar aparelhos/equipamentos e disponibilizar os canais escolhidos. Acesso administrativo ao painel/SSH não foi fornecido; as verificações externas não comprovam configurações internas de volume ou recuperação. [Easypanel](deploy/easypanel/README.md), [deploy](deploy/README.md) e [mobile](mobile/README.md) contêm os requisitos. Troca de chave MFA pelo procedimento inicial é recusada se já houver contas; nunca reproduzir segredos de capturas ou incluí-los no Git.


A entrega de comunidade adiciona fichas públicas para contas do condomínio (edição pela gestão de pessoas), fotos no volume privado, calendário compartilhado optativo e mural com alerta por usuário/versão. O menu agora tem busca, grupos, estado ativo e gaveta móvel, com nome do condomínio destacado. Consulte [COMUNIDADE_E_PROXIMAS_INTEGRACOES](fundacao/COMUNIDADE_E_PROXIMAS_INTEGRACOES.md) para os detalhes e o próximo ciclo: perfis ampliados, acesso temporário somente durante estadia e anual limitado ao contrato, agente para grupo WhatsApp e Asaas. O canal existente é Telegram; não tratá-lo como WhatsApp. API Asaas sem tarifa própria; recebimentos/mensagens são pagos. Tarifas atuais do Mercado Pago não puderam ser confirmadas (HTTP 403); SDK gratuito não comprova processamento gratuito.

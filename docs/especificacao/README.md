# Especificação

A especificação completa do Vilazuni v1.0 (17/11/2026) tem três arquivos:

- `Vilazuni_Prompt_Claude_Code.txt` — requisitos, fases e os 58 testes de aceite;
- `Vilazuni_Projeto_Chandra.pdf` — decisões do projeto e manual operacional;
- `Vilazuni_Calculadora_Piscina.xlsx` — orçamento editável da piscina.

**Eles ficam fora do git** (pasta `privado/`, no `.gitignore`) enquanto este repositório for público: trazem o endereço do condomínio piloto e o estado da segurança física do local. Quem trabalha no projeto recebe os arquivos do dono e os coloca em `docs/especificacao/privado/`.

Os documentos versionados (`docs/PLANO.md`, `docs/requisitos.md`, `docs/adr/`) citam os requisitos pela seção, sem esses detalhes.

Em divergência, valem os requisitos de segurança; a questão é registrada antes de mudar uma regra de negócio.
